# Project Starting Point
## Selected project area
Financial-Agent Deployment
## Why our team is interested in it
Our team is interested in exploring how AI agents can use financial data to support different business decisions. Using Spotify's publicly available financial information, we want to determine if we can make future predictions for the financial direction the company should take. Either next steps for specific financial decisions or major merger & acquisition decisions.
## Candidate Vision A
A financial analyst must utilize Spotify's financial data and pull conclusions about the financial performance of Spotify in various areas.
## Candidate Vision B
A content strategy executive at Spotify must decide how the company's financial performance should inform priorities for upcoming merger & acquisitions negotiations
## Core data source we confirmed we can access
Spotify Investor Relations: Financials
https://investors.spotify.com/financials/default.aspx 
We confirmed access to Spotify's publicly available financial materials, including quarterly results, financial statements, annual reports, and SEC filings.
## Three questions we still need to resolve
1. Does Spotify's publicly available financial data contain enough information to meaningfully support each of our proposed decisions?
2. Which financial analysis tasks for each candidate Vision could be reliably delegated to an AI agent, and which would still require human or deterministic review?
3. Which Candidate Vision provides a more specific, useful, and realistically testable application of the available Spotify data?
